# Getting Started

Use the repository's versioned documentation as the source of truth:

- [Primary documentation](https://github.com/embeddedos-org/.github/blob/master/README.md)
- [Contribution guide](https://github.com/embeddedos-org/.github/blob/master/CONTRIBUTING.md)
- [Releases](https://github.com/embeddedos-org/.github/releases)

Prerequisites, build commands, supported targets, and run instructions vary by
repository. Do not infer commands from another EmbeddedOS component. If the
documented path is incomplete, open a
[documentation issue](https://github.com/embeddedos-org/.github/issues/new/choose).
