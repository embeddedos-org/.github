# Security

Do not disclose vulnerabilities in public Issues, Discussions, pull requests, or Wiki edits.

Follow the [repository security policy](https://github.com/embeddedos-org/{{repository}}/security/policy). If the repository inherits the organization policy, it provides the private reporting route and supported-version guidance.

Include the affected repository, version or commit, reproduction details, and impact only through the private reporting channel described by that policy.
