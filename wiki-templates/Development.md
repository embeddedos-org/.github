# Development

Read the
[repository contribution guide](https://github.com/embeddedos-org/{{repository}}/blob/{{default_branch}}/CONTRIBUTING.md)
and its build manifests before changing code.

Every human-authored pull request must close a real issue in this repository
with `Fixes #123`, `Closes #123`, or `Resolves #123`. Cross-repository
references and ordinary mentions do not satisfy the policy.

Use [Discussions](https://github.com/embeddedos-org/{{repository}}/discussions)
for questions and early design exploration. Use
[Issues](https://github.com/embeddedos-org/{{repository}}/issues) for actionable
work and [Projects](https://github.com/embeddedos-org/{{repository}}/projects)
for prioritization and delivery tracking.

Run the repository-specific tests and linters documented in the source tree.
Record the exact commands and outcomes in the pull request.
